## How to use

1. Pick a track and start from lecture 01 — files are numbered in teaching order.
2. `CCNA/0.Course contents.pdf` gives the full CCNA course outline.
3. Practise every topic in a lab (GNS3 / EVE-NG / CHR for MikroTik) while reading.
